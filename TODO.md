# GMIU Website Outcomes

- **Polished welcome screen:** The website features the GMIU name or monogram, “GMIU College Chatbot” title, concise description, and a prominent Start Chat button.
- **Deterministic chatbot coverage:** The server returns predefined answers selected through explicit `if / else if / else` logic only, without AI APIs, machine learning, an LLM, or a database, and includes a helpful fallback for unrecognized questions.
- **GMIU information coverage:** Predefined answers cover GMIU identity and full form, Bhavnagar location and address, official website, courses and programs, departments, admissions, application process, eligibility, fees, scholarships, hostel, transportation, campus, facilities, library, laboratories, extracurricular activities, placements, recruiting companies, phone number, and email.
- **Social exchanges:** Greetings, thanks, and goodbye messages receive appropriate predefined replies.
- **Modern chat interface:** Bot messages align left, user messages align right, and the page includes a text input, send button, and scrollable conversation history.
- **Conversation controls:** Clear chat, automatic scroll-to-latest, input validation, and a typing/loading animation are implemented.
- **Suggested topics:** Topic chips provide quick access to common GMIU questions.
- **Responsive accessibility:** Desktop and mobile layouts, keyboard-friendly controls, readable contrast, focus states, semantic HTML, and touch-friendly sizing are included.
- **Official verification links:** The GMIU website and admission portal are linked where changing details should be verified.
- **Share-ready presentation:** The site offers a cohesive educational experience from orientation through active chat and exposes a stable preview on port 3000.
